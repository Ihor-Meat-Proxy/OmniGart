# shared/hydration

Pure-Kotlin (KMP JVM) hydration domain: beverage catalogue models, BHI counting, daily norms, caffeine limits / late-caffeine insight, Health sync contracts + fakes, quick-log and smart-reminder logic.

Content lives in `content/beverages/`. No app-shell UI in this module.

```bash
./gradlew :shared:hydration:jvmTest
```
