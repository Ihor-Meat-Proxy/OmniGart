# Running content pack

Bundled-first workout types and race plans. No pacing/HR algorithms here — those belong in a separate activity-algorithms module.

## Layout

- `workout-types/` — easy, tempo, intervals, fartlek, long, hill, strides (~25)
- `plans/` — 5K / 10K / half / marathon × beginner / intermediate
- `schema/` — JSON Schema (Draft 2020-12)
- `locales/en-GB.json`, `locales/uk.json`
- `evidence.json` — citation registry pointers

## Intensity labels

HR zones `z1`–`z5` and pace zones `easy` / `marathon` / `threshold` / `interval` / `repetition`.
