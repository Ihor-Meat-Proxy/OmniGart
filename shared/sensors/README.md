# shared/sensors

Pure Kotlin Multiplatform logic for BLE heart-rate parsing, RR artefact correction,
HRV metrics, Polar client contracts, and swim-strap merge.

No Polar / CoreBluetooth / HealthKit / Health Connect dependencies.

```bash
./gradlew :shared:sensors:jvmTest
```

See `docs/sensors/WIRING.md` and `docs/sensors/POLAR_OFFLINE.md`.
