# PDF fonts (OFL)

- `NotoSans-Regular.ttf` / `NotoSans-Bold.ttf` — Latin, Greek, Cyrillic (uk, be, kk)
- `NotoSansGeorgian-Regular.ttf` — Georgian (ka)

Source: [googlefonts/noto-fonts](https://github.com/googlefonts/noto-fonts) (SIL Open Font License 1.1).

zh-Hans uses the platform CJK cascade (PingFang SC / Noto Sans CJK) — full Noto Sans SC is too large for the app size budget.
