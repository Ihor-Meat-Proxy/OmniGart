# android/sensors

Android library: standard BLE Heart Rate Service client, Polar BLE SDK **8.4.0**
adapter, and a `connectedDevice` foreground service.

Standalone until PR #2 adds AGP to the root project. See `docs/sensors/WIRING.md`.

```kotlin
implementation("com.github.polarofficial:polar-ble-sdk:8.4.0") // JitPack
```
