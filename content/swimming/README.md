# Swimming content pack

Bundled-first strokes, drills, and sessions. Critical Swim Speed (CSS) sessions reference CSS as a **target label** only — computation lives outside this pack.

## Layout

- `strokes/` — freestyle, backstroke, breaststroke, butterfly, individual medley
- `drills/` — technique library (~30) with coaching text
- `sessions/` — technique, endurance, CSS-interval, and mixed sessions (~20)
- `schema/` — JSON Schema (Draft 2020-12)
- `locales/en-GB.json`, `locales/uk.json`
- `evidence.json` — citation registry pointers
