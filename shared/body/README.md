# shared/body

Pure-Kotlin body measurements domain: weight, circumferences, skinfolds, local-only progress photo metadata, body-fat strategies (CUN-BAE default, U.S. Navy, Jackson–Pollock 3/7, BMI + waist-to-height wellness framing), EWMA trend smoothing, and Health sync contracts/fakes.

Locales: `content/body/locales` (en-GB + uk). Spec: `docs/specs/body-health-sync.md`.

```bash
./gradlew :shared:body:jvmTest
```
